# API de Cadastro de Usuários

Projeto desenvolvido para estudar ASP.NET Core.

## Tecnologias

- ASP.NET Core
- Entity Framework Core
- SQL Server
- JWT
- BCrypt
- Swagger

## Funcionalidades

- Cadastro de usuários
- Login
- Autenticação JWT
- Autorização por Roles
- CRUD
- Validações
- Hash de senha
- Paginação

## Endpoints

POST /login

POST /usuarios

GET /usuarios

PUT /usuarios/{id}

DELETE /usuarios/{id}
